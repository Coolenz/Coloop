# Coloop 设计规范

## 当前方案：极简桌面应用

以任务操作和真实设备状态为核心。移除个人问候、署名、大型装饰字母与没有功能含义的颜色。所有可见产品名称统一为 **Coloop**，内部 npm 包名、IPC API 和资料目录继续使用已有标识，以保持兼容。

用户明确选择类似 macOS 的极简桌面风格。采用浅灰侧栏、白色主工作区、轻微浮起的任务输入和柔和的分组层级。增加内容留白，减少边框密度；快捷入口从独立盒子变成轻量操作项。保留原生 Windows 窗口行为，不添加仿制的系统按钮。

方案审核：用表面明度、16px 容器圆角和少量浅阴影表达层级；不使用大面积渐变或高饱和背景。主要动作沿用品牌蓝，导航选中态使用白色表面。整套页面仍共享同一份样式与相同的布局规则。

### 统一规则

- 网格：4px 基础单位，以 8 / 16 / 24 / 32px 作为主要间距。
- 结构：208px 导航、280px 上下文栏、中央弹性工作区；各页面使用相同的 32px 内容边距与标题基线。
- 字级：24px 页标题、16px 区域标题、13px 正文、11px 辅助信息；正文行高 1.6，标题行高 1.3。
- 圆角：16px 内容容器、10px 输入与按钮、6px 状态标签。图标统一 16 / 20px，线宽 1.7。
- 控件：按钮 36px、输入 40px；每个操作区域只有一个强调主按钮。
- 色彩：画布 `#fafafb`、表面 `#ffffff`、正文 `#292c34`、辅助 `#737783`、边界 `#eceef2`、主色 `#5364db`。绿色仅表示已连接或成功，琥珀仅表示提醒，红色仅表示失败或删除。
- 层级：用对齐、留白、字重与表面明度表达结构；浅阴影仅用于主任务画布、选中导航和浮层。
- 行为：导航、表单、空状态和反馈使用同一套组件。键盘焦点明显，遵从减少动态效果设置。

### 品牌

字标固定为 **Coloop**，不加句号、个人名字或额外署名。标志由两个相同半径的圆构成：开口 C 与闭合回环连接；单色、等线宽、固定几何比例，可在 16px 图标尺寸下辨认。源文件 `resources/brand.svg` 与 PNG、ICO 同步生成。

### 页面网格

```text
208px 导航 │ 32px 内容边距 + 主工作区 + 32px │ 280px 上下文
           │ 工作台                工作区状态 │ 设备连接
           │ 标题描述                         │ 型号 / 状态
           │                                  │ 连接动作
           │ 新建任务                         ├────────────
           │ 任务内容                         │ 能力状态
           │ 上下文             模型 / 运行   │ OCR / 云端 / RK
           │                                  ├────────────
           │ 快捷操作                         │ 数据处理说明
           │ 最近任务                         │
```

审核重点：不依靠换色修饰旧版；重新整合样式入口，所有页面遵从同一套 tokens。记录为空时保持真实空状态，设备状态仅来自实际连接。窄窗口允许折叠上下文栏并保留设备管理入口。
