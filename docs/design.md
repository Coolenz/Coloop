# Coloop 设计规范

当前 0.6.1 设计系统以根目录 [DESIGN.md](../DESIGN.md) 为准，机器可读扩展与组件预览位于 [.impeccable/design.json](../.impeccable/design.json)。本文件保留为文档入口。

用户最新确认的方向是黑白：石墨黑导航、白色任务工作区、浅灰设备栏；石墨黑主操作与灰阶反馈。当前导航项使用白底黑字，快捷操作改为紧凑列表行。此方向覆盖此前蓝色界面与竖直标志的描述。

Logo 保留对称双闭合半圆及轻重不同的连续轮廓，整体恢复 −35° 倾斜；界面借用圆角与线条轻重，功能控件保持水平。Sora 本地可变字体仅用于 Coloop 字标；功能文字沿用 Windows 字体栈。页面主标题 27px，输入标题 21px（紧凑桌面 18px），任务输入容器圆角 20px，按钮与字段圆角 10px。

六个页面共享样式与真实状态。默认导航 212px、设备栏 276px、页面边距 32px；小窗口隐藏设备栏并保留设备管理入口。窗口最小 1060 × 720px，长页面纵向滚动。精确 tokens、组件状态和响应规则见根目录规范。

方向与页面任务见 [frontend-redesign.md](frontend-redesign.md)。本记录从实际源码提取；Impeccable 引擎下载失败，context 与 concept-seed 均未产生有效引擎结果，不表示自动设计检查已通过。

深色主表面为 #202124，抬升与悬停使用 #2b2e33 / #383c43；Logo 底色同步，维持最新倾斜几何。
