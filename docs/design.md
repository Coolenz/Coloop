# 界面设计

## 第二版：coolen 的个人工作台

这次重设计解决首版层次薄、品牌识别弱、任务输入缺少重点的问题。保留既有桌面能力，建立独立于通用管理后台的产品语言。

- 色彩：深海蓝 `#202b43`（导航）、瓷白 `#f7f8fc`（工作区）、鸢尾蓝 `#5868e9`（动作）、杏橙 `#f5b17b`（品牌点睛）、墨蓝 `#28334b`（正文）、灰蓝 `#768198`（辅助信息）。
- 字体：Segoe UI Variable Display 负责英文品牌与大标题，Microsoft YaHei UI 负责中文；正文 13px，标题 29px，任务输入 18px，避免首版小字过多。
- 标志：从 coolen 的开口 c、双 o 和 e 的横杠提取结构。两条相接的圆弧形成双镜头轮廓，开口代表输入与输出，e 的横杠形成连接桥，杏橙端点作为识别特征。保持 Coloop 名称，标注 by coolen。
- 布局：深色左导航承载品牌；中央为白色任务画布；右侧是独立设备模块与能力清单。首屏重点落在可直接操作的任务输入，空状态有明确入口。
- 细节：按钮和表单统一高度，导航有选中指示，硬件示意图增加端口和芯片层次，识别框与结果文本保持对齐；交互动效只响应用户操作。

方案审核：不单纯增加卡片或渐变装饰。品牌的双镜头弧线与主任务画布承担辨识度；其余页面使用同一套间距、字级和表面层级。设备状态仍来自实机，空历史保留真实空状态。标志同时更新到导航、任务头像、Windows 图标与导出素材。

以下保留首版方案作为设计演进记录。

以「连接设备、看懂屏幕、完成任务」为主线。主要用户为在 Windows 上使用 RK 边缘计算设备的人。

## 设计 token

- 雾白 `#f6f7f9`：工作区底色。
- 石墨 `#202731`：正文和标题。
- 钴蓝 `#4169e1`：选中状态、执行动作、品牌回环符号。
- 松绿 `#21836a`：实测连通、完成状态。
- 琥珀 `#ad741c`：未配置和需要处理的状态。
- 浅钢 `#e4e8ee`：边界与连接线。

字体使用 Windows 内置的 Segoe UI Variable 与 Microsoft YaHei UI；中文正文 13–14px，页标题 28px，重要任务输入 18px。

## 布局

左侧窄导航 + 中间任务工作区 + 右侧设备与上下文检查器。默认左对齐。中央输入与屏幕上下文构成视觉中心，右侧只有真实状态。

```text
┌───────────┬────────────────────────────────┬──────────────────┐
│ Coloop    │ 工作台 / 概览                   │ 本地工作区       │
│           ├────────────────────────────────┴──────────────────┤
│ 工作台    │ 让想法，进入工作。              │ 设备连接         │
│ 屏幕理解  │                                │ USB / RK3588     │
│ 工作流    │ [任务输入 / 上下文 / 执行]      │ 状态与资源       │
│ 模型连接  │                                │                  │
│ 设备管理  │ 快捷工作流                     │ 当前能力         │
│ 运行历史  │ 最近任务                       │                  │
└───────────┴────────────────────────────────┴──────────────────┘
```

审核：避免通用数据看板堆叠统计卡；设备状态围绕真实连接展开，未连接时展示操作指引。唯一突出的视觉是蓝色回环标志与任务输入区域；没有无意义性能数字、虚假进度或预设成功记录。屏幕识别与任务结果使用同一套上下文区域，避免复制粘贴。
