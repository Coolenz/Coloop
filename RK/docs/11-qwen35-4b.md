## 量化选择

本次使用社区预转换模型，语言部分 W8A8、视觉部分 FP16，没有自行重新量化。

已核对官方 RKLLM 1.3.1 的性能表：RK3588 对应 W8A8；Qwen3.5 的 W4A16 / W4A16_g128 数据位于 RK3576 小节，不能拿 RK3576 的模型给 RK3588 使用。另核查 Qengineering、HanzoHuang 和 Firefly 的 4B 仓库，RK3588 发布文件均为 W8A8。这里的“最小”限定为当前已验证支持的 RKLLM / NPU 路线，不是声称 CPU、GGUF 或其他推理引擎不存在更低位宽格式。

- [官方平台性能表](https://github.com/airockchip/rknn-llm/blob/main/benchmark.md)
- 本机 Toolkit 1.3.1 补充验证：使用已有随机小型 Qwen2 检查平台参数，`target_platform='rk3588', quantized_dtype='w4a16'` 返回 `-1`，明确报错 `rk3588 not support quantized_dtype: w4a16`。日志为 `logs/qwen35-4b/quant-support.txt` / `quant-support.json`。这是平台支持检查，没有转换完整的 Qwen3.5-4B。
- [社区模型仓库](https://huggingface.co/Qengineering/Qwen3.5-4B-rk3588)
- 模型固定版本：`ee09c44b420e031dbe96fcb489ef30c5f3e0d1a5`。
- [社区应用源码](https://github.com/Qengineering/Qwen3.5-4B-NPU)，固定版本 `df7a244d43de018d6f2eec11cab6b6967039eacd`。
- 应用内 RKLLM Runtime/Header 1.3.0，与模型转换版本匹配；现有 9B 和 DeepSeek 环境保持各自目录。

| `qwen3.5-4b_vision_rk3588.rknn` | 704,579,761 | `36648344b174e5681b26004f5b9d417fc38b30e119836645f683cd174fbada60` |

## 准备与部署

```powershell
cd D:\RK
.\.venv\Scripts\python.exe tools\prepare_qwen35_4b.py --mirror
.\.venv\Scripts\python.exe tools\deploy_qwen35_4b.py
```

下载分片及上传均支持续传。主机与板端分别检查 SHA256，上传校验通过才将 `.partial` 改为正式文件名。

本机包位于 `deployment/qwen35-4b`，板端位于 `/home/cat/rk-edge-ai/qwen35-4b`。源码核心与 9B 上游一致，复用相同补丁；生成文件及摘要见 `deployment/qwen35-4b/source-manifest.json`。应用在板端通过 CMake 编译。

双击根目录的 **运行Qwen3.5-4B.cmd** 或 **看图Qwen3.5-4B.cmd**。默认上下文 16384、最多输出 128 token、关闭思考。仍需退出其他大模型应用后运行。

## 验证

```powershell
.\.venv\Scripts\python.exe tools\smoke_qwen35.py --board-subdir qwen35-4b
.\.venv\Scripts\python.exe tools\smoke_qwen35.py --board-subdir qwen35-4b --image --tokens 128
```

同题复测使用与 9B 相同的八次测试、每题独立进程、2048 上下文、64 输出 token。测试分别记录进程状态和回答质量，不把退出码 0 视为答案正确。

### 2026-10-28 实测结果

两个模型均已下载并上传，主机与板端 SHA256 校验通过。实际使用 RK3588 NPU 三核推理，Runtime 1.3.0、驱动 0.9.8。当前仍为实验部署：基础任务有改善，但算术应用题验收失败。

| 测试 | 实际结果 | 人工核对 |
|---|---|---|
| 20 元买 3 支笔，每支 4 元（中文，独立进程重复 3 次） | 三次均为“还剩 2 元。” | 三次均错误，应为 8 元 |
| 2 加 3，只答数字 | `5` | 通过 |
| 20 减 12，只答数字 | `8` | 通过 |
| 中国首都，只答城市名 | `北京` | 通过 |
| 原样输出“你好世界” | `你好世界` | 通过 |
| 同一道买笔题的英文版本 | `2` | 错误，应为 8 |

八次小测试四次满足要求、四次失败；包括重复题，不能当作模型总体准确率。所有进程正常退出，最高监测温度 51.769℃。逐题记录及人工复核见 `logs/qwen35-4b-retest-20261028-223606/summary.json`。

月球样例看图识别出宇航员、月球表面、背景地球和绿色啤酒瓶；关于人体姿态与箱子的描述不够准确，不代表完整视觉准确率验收。

- 单次初始化约 10.51 秒，包含预填充的问答约 27.86 秒，完整进程约 41.64 秒。
- 生成 109 token，约 **4.90 token/s**。
- `/usr/bin/time` 最大 RSS 为 **5,686,532 KiB，约 5.42 GiB**；该进程记录 Swaps 为 0。
- 同一张图片的既有 9B 记录为约 2.94 token/s、9.15 GiB。模型输出长度不同，且缓存状态未统一，因此这里只比较样例观测，不视为严格性能基准。
- 原始记录位于 `logs/qwen35-4b/qwen35-image-smoke.txt` 和对应状态 JSON。
