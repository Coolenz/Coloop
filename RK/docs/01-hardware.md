# 硬件与配件清单

## 先确认板型

官方将普通 LubanCat-4 列为 RK3588S；BTB 核心板列为 RK3588S2。它们属于 RK3588 系列，不能据此认为接口、电源和镜像都相同。普通 4 / V1 与 BTB 底板应分别核对。

| 板型 | 官方列出的供电规格 | 购买或接线时确认 |
|---|---|---|
| 普通 LubanCat-4 / V1 | Type-C，5V/4A | 使用适配该板的电源与线缆，辨认供电口和 OTG 口 |
| LubanCat-4-BTB 配套底板 | DC，12V/2A | 核对底板型号、插头与极性，按对应规格供电 |

Debug 默认参数为 1500000、8 数据位、无校验、1 停止位。以上信息来自[野火硬件说明](https://doc.embedfire.com/linux/rk3588/quick_start/zh/latest/quick_start/lubancat/lubancat4.html)，最终以实物版本标识和配套手册为准。

## 先准备这些

下面是本项目的准备建议，不是全部都要新买。已有配件先核对能否使用。

| 优先级 | 配件 | 数量 | 用途 / 选择建议 |
|---|---|---:|---|
| 必备 | 匹配板型的电源 | 1 | 优先原厂配套，稳定供电 |
| 必备 | 适配散热器 | 1 | 根据安装孔和芯片位置选择；持续 AI 负载建议配风扇 |
| 建议先用 | 网线及可用路由器端口 | 各 1 | 让电脑、板子处于同一局域网，便于 SSH 和安装依赖 |
| 刷机时需要 | 支持数据传输的 USB Type-C 线 | 1 | 电脑连接板上 OTG 接口；只有充电功能的线不能刷机 |
| 按情况 | microSD 卡及读卡器 | 各 1 | 无可用 eMMC 系统或想从卡启动时需要；建议从 32GB 起考虑，视镜像大小调整 |
| 调试建议 | 官方兼容 USB 转 TTL 调试器及线 | 1 套 | 网络不可用时读启动日志；购买时确认支持 1500000 波特率和板端逻辑电平 |
| 摄像头阶段 | Linux UVC 兼容 USB 摄像头 | 1 | 优先查清兼容性，可先借用已有设备验证 |

如果出厂 eMMC 系统可用，可以先不买启动卡。板子已能通过 SSH 登录时，显示器、键盘、鼠标均可暂缓。

USB 转 TTL 调试线按手册连接 GND、TX、RX：TX 与 RX 交叉。不要把 RS232 转换器直接接 TTL Debug 接口；不要把调试器 VCC 当作板卡主电源。首次接线前确认针脚位置与电平。

## 按项目再补充

- 显示器和与实物接口匹配的 HDMI 线：用于本地桌面调试；普通 4 的 HDMI 形态需核对，不要套用其他板型接口。
- MIPI 摄像头：等 USB 摄像头流程跑通后再选，需要匹配传感器、排线、连接器和镜像驱动。
- Wi-Fi 模块：确实需要无线网络时再买，先确认板型、接口与驱动。
- SSD、4G 模块、MIPI 屏幕、扩展板：由应用需求决定，入门阶段不必一次配齐。

MIPI、PCIe 等设备应在断电后连接。[首次启动注意事项](https://doc.embedfire.com/linux/rk3588/quick_start/zh/latest/quick_start/board_startup/board_startup.html)
