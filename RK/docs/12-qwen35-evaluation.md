# Qwen3.5-4B 更换测试集的实测记录

日期：2026-10-28（Asia/Shanghai）。本次只测试当前 4B，未重新测试 9B。

## 结论

原来的八次测试包含三次重复的买笔题，不能代表整体能力。本次新增 48 次独立进程测试后，基础非数学任务的表现明显好于此前单看算术题的印象。但尚未进行官方原始 BF16/FP16 同题对照，不能将现象确定归因于量化，也不能把该结果外推为原始 Qwen3.5 的整体准确率。

| 题组 | 内容或原标注一致结果 | 完全遵循请求 |
|---|---:|---:|
| 自编非数学基础诊断 | 20/20 内容正确 | 19/20 |
| 自编数学对照 | 3/4 内容正确 | 2/4 |
| 公开 CMMLU 非数学子集 | 19/24 与原始答案一致 | 24/24 输出合法单个选项字母 |

自编非数学题涵盖常识、短文阅读、信息提取、翻译、分类、指令遵循和简单非数值推理。一个格式错误是把要求的英文逗号写成中文逗号。

数学对照中，`20-3*4` 算出 8，但附加了算式，未满足“只回答数字”；6×7 回答 42；给定总价 12 元、支付 20 元的找零题回答 8；原买笔题仍错误回答“还剩 2 元”。因此问题也不是所有基础数学都失效，而是至少存在对特定应用题的稳定错误。

## 实验设置与边界

- 模型：现有 Qengineering Qwen3.5-4B W8A8，固定模型版本未变，视觉编码器未加载。
- 板端目录：`/home/cat/rk-edge-ai/qwen35-4b`，Runtime 1.3.0，RKNPU 驱动 0.9.8，RK3588 NPU 三核。
- 每题重新启动模型进程，关闭历史；上下文 2048，关闭思考，`top_k=1`。其余采样参数沿用已有 Runtime 默认值。
- 输出上限为 128 token，较旧的八次小测 64 token 提高；本次均为短答案，未以复杂长推理作为评测目标。
- 全部 48 次进程正常退出，无温度或时间中止。基础组最高监测温度 49.0℃；公开组 48.076℃。
- 回答内容正确、输出格式是否符合要求、进程是否正常结束分别判断。
- 当前设置与[Qwen 官方建议的采样参数](https://huggingface.co/Qwen/Qwen3.5-4B#best-practices)不同。此次没有变更思考或采样参数，也未测量它们的因果影响。

因此 19/24 指与题库原标注的字母一致程度，不能简单将全部五个差异当作已经确认的模型知识错误。这个小子集也不能与完整 CMMLU 榜单分数比较。
