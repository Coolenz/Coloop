# 实机网页验收

- 用户已明确授权直接脚本操作。网页定位、导航、交互和验证可使用 Playwright 脚本或浏览器连接器，绑定工具返回的浏览器/标签页和明确 URL。
- 不使用原生 Windows 电脑操作工具选择、激活或输入 Edge 窗口：该路径已重复发生 URL 无法确认并终止整轮的问题。
- 原生电脑操作工具可用于 Coloop、记事本等非浏览器软件。遵守适用工具/技能的操作和停止要求。
- Coloop 模型自主执行、脚本执行器实测和验收连接器直接操作必须分别记录，后者不能冒充前者。
- 证据、恢复流程及已知问题参见 ../docs/real-device-acceptance.md。
