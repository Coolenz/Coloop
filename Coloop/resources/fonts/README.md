# Sora

`Sora-Variable.ttf` 来自 Google Fonts 官方字体仓库：

- 字体源文件：https://github.com/google/fonts/blob/main/ofl/sora/Sora%5Bwght%5D.ttf
- 许可证源文件：https://github.com/google/fonts/blob/main/ofl/sora/OFL.txt
- 本地许可证：`OFL-Sora.txt`（SIL Open Font License 1.1）

字体未修改，仅用于 Coloop 品牌字标与品牌预览。功能界面继续使用 Windows 系统字体。字体文件随应用本地打包，运行时不向外部字体服务发起请求。
