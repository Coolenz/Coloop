## 本轮修复

### 模型与任务入口

官方 Agent TARS 负责实际循环、工具调度与最终答案。补齐 RK 模型的 OpenAI 流式适配、真实多轮角色、工具结果压缩和已核验结束提示。云端请求失败可在同一任务中切换本地路由，保留命令回执。手机入口接入同一个执行服务，支持中文和跨字段操作。电脑操作页允许使用已就绪的本地模型。

### 编辑、焦点与剪贴板

修复收起上位机窗口后焦点被覆盖，以及记事本 UIA 指向非活动标签页的问题。局部修改通过唯一原文匹配计算完整正文，使用受守卫的 RK 输入，再核验完整正文。文件名对话框的编辑记录与正文编辑区分别绑定。

剪贴板租约保留可物化的公开格式数据，并处理记事本的空句柄 `EnterpriseDataProtectionId` 标记。OLE 传输封装不进行原始指针复制。独立验证器在本机对公开数据逐格式计算摘要，正常还原、到期和释放路径均有真实测试。不可物化的延迟格式具有所有者生命周期限制，完整保留全部剪贴板格式的能力仍有限。 [Microsoft 剪贴板操作说明](https://learn.microsoft.com/en-us/windows/win32/dataxchg/clipboard-operations)

### 文件与 WPS

增加任务目录能力，通过正式任务请求或文件夹选择器授权范围。复制、文本、ZIP 和 WPS 工作簿分别记录 `host_filesystem`、`host_wps_com`，RK 输入记录为 `rk_hid`。

工作簿输入先复制到任务内唯一临时文件，WPS 只处理该副本。输出先暂存、重开检查，再提交至新文件。已有不同内容的输出保留，修正时使用唯一新文件名。修复 XLSX 默认关联缺失，以及 WPS 内部窗口与顶层窗口不一致导致的展示失败。

扫描 PDF 通过 Windows PDF 渲染和现有离线 RapidOCR 识别，返回页码、页数与截断标记。CSV 增加物理来源行号和分页读取。文本按 Unicode 字符分页。原始来源摘要用于核对读取一致性。

### 停止与停滞

已增加停止确认等待正在执行的宿主工具收束，避免模型循环结束后仍有工具调用未收束。WPS 取消时等待静态工作进程关闭所属工作簿。

新增十五分钟无有效进展诊断，保留任务并通过官方请求钩子提示继续诊断。阶段变化、重复读取相同来源和新时间戳不会刷新有效进展。真实交付或新来源分段会清除停滞标记。已完成模拟时钟回归，真实十五分钟分支已通过。证据分别在 `A05/r22` 和 `A05/progress-r24`。长文档采用受控本地文件分批到达及文件占用的类似场景，未声称完成飞书在线长文档平台验收。

修复被动推荐失败覆盖已完成任务错误状态的问题，推荐错误与任务执行错误分别记录。

### 语音入口开发

本机具备中文 Windows 离线识别器。已补充 WAV 指令导入、置信度显示和可编辑转录，r23 发布包界面和 RK 执行联测已通过。原生后端实际识别短指令“将计划改为语音验证完成”一致。较长指令中的“其他内容保留”识别为“其他那种保留”，保留该失败，完整语音场景仍待验收。语音输入采用合成 WAV，物理麦克风分支需分别记录。
