# Coloop 实机验收工具与证据

## 网页验收方式

网页操作、页面定位与结果读回使用 Playwright 脚本或 Edge 浏览器连接器，绑定受管浏览器、标签页和明确 URL。原生 Windows 窗口接口只用于 Coloop、记事本等桌面软件，不用于选择、激活或输入 Edge 浏览器窗口。

原生 Windows 验收工具曾两次因无法可靠确认 Edge URL 而要求终止整轮操作。这是验收工具的地址识别失败，不是 Coloop 任务结果。切换到按标签页绑定的浏览器接口后，本地表单的真实填写、点击和结果读回通过。

恢复流程：

1. 从浏览器连接器返回的标签页清单选择准确标签页，保留浏览器和标签页绑定。
2. 新标签页先使用浏览器的 `goto` 导航到明确测试地址，再读取页面 URL 和页面身份。
3. 网页交互使用该标签页的 DOM/可访问性接口，结果以 URL、页面文本和截图确认。
4. 标签页失效后，使用连接器重新绑定；不得把旧窗口句柄或过期索引当成当前页面。
5. 连接器超时和原生工具的策略终止分别记录为基础设施问题。遵守工具停止要求；不要反复调用同一原生 Edge 操作，不修改或关闭安全检查。

## 证据边界

- 连接器填写成功，只能证明连接器可用，不能计作 Coloop 自主执行成功。
- Coloop 操作验收必须由 Coloop/RK 发出输入，并同时记录实际屏幕结果和任务状态。
- 人工切回目标窗口、手动填写或点击，都要在报告中明确标注。
- 公开网页导航遇到网络或连接器超时，记录阻塞，不能计作通过。
- 软件操作验收与网页工具验收分别记账；存在未通过项时不能宣布全面可用。
