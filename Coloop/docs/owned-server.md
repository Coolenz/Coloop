# 自有服务器连接

Coloop 的应用消息服务位于 `server/relay.mjs`。电脑通过 HTTPS 长轮询主动连接服务器，安卓端访问固定的配对与会话消息接口；不提供 TCP 隧道、任意 URL 代理、端口转发或 VPN。服务只传递已有协议的密文，解密和执行仍在电脑端。

## 访问控制

- 安卓端发送 `X-Coloop-Access-Key`。服务器保存 scrypt 加盐校验值，未带或错误口令的发现、配对、RPC、健康检查请求均返回 401。
- 电脑连接使用独立随机 256 位 Bearer 密钥。访问口令不能代替电脑密钥注册电脑。
- 手机仍需通过电脑本地生成的五分钟一次性二维码配对，并使用独立 AES-256-GCM 密钥签名加密消息。只有访问口令不能控制电脑。
- 口令和电脑连接密钥在桌面用 Windows DPAPI 保存；手机口令和配对密钥在 Android Keystore 保护的存储中保存。普通状态快照不返回它们。
- 配对码包含服务器访问口令和一次性配对密钥，只应在本机显示或私下传递。不要公开二维码、配对链接或服务器连接文件。

## 服务部署

服务器运行 Ubuntu 24.04。Node.js 服务以独立 `coloop` 系统用户运行，绑定 `127.0.0.1:8787`，由 Nginx 提供公网 HTTPS。80 端口只响应证书 HTTP-01 验证路径，其他路径返回 404；443 提供要求鉴权的 API。不修改 SSH 密码、密钥或既有规则。

`scripts/prepare-relay-deploy.mjs` 从本机私有文件生成部署包。电脑随机密钥只留本机，部署命令仅包含它的 SHA-256 哈希；服务器访问口令仅发送盐和 scrypt 校验值。不要把本机私有连接配置提交到仓库或打入通用安装包。

```powershell
# 在当前进程环境变量 COLOOP_SERVER_ACCESS_KEY 中提供访问口令后：
node scripts/prepare-relay-deploy.mjs <服务器公网IPv4>
```

生成的 `.qa/relay-deploy/install-command.sh` 通过已登录的阿里云命令助手执行。安装脚本需要 root，安装隔离的 Node.js 24 LTS、Nginx 和 Certbot，创建服务与证书续期定时器。执行前需确认安装范围和证书 CA 服务条款；服务器已存在 Coloop 配置或相关端口已占用时拒绝覆盖。

无域名时使用 Let's Encrypt 公网 IP 短期证书，每天两次检查续期，续期后检查并重新加载 Nginx。不能把六天有效证书当作一次性安装；应保持续期任务启用并监控失败。生产环境的实际证书、服务状态和连通性必须独立验证。

## 客户端

在「Agent 协调 → 安卓手机连接」导入私有的服务器 JSON 配置，然后开启手机连接。二维码会携带服务器地址及口令，安卓 0.2.0 扫码后使用。电脑端关闭手机连接会撤销当前服务器连接，现有手机设备仍可以从电脑立即解绑。

保留明确标示的 Cloudflare 临时连接兼容入口；配置了自有服务器后，失败时不会回退到 Cloudflare。配置损坏时显示错误并要求重新导入，也不回退。

## 传输与失败边界

服务器内存中的请求有数量、大小和超时限制，不持久保存消息正文。一个请求最多投递给电脑一次；断线、超时、重连不会重投递队列里的旧指令。电脑原有协议继续校验 epoch、序号、请求标识、GCM 标签和到期时间。网络结果不明时应刷新回执再决定下一步。

公网入口仍然可被扫描或尝试访问；鉴权保护接口数据和操作，不能隐藏服务器 IP。跨境网络质量需要在实际手机运营商网络测试，开发机或模拟器成功不能替代真机异网验收。

## 连接可靠性升级（2026-10-31，线上待更新）

本轮完成通信后端与配套上位机的可靠性改进，后端发布标识为 `2026.10.31.1`。518 项单元测试及类型检查、生产构建通过。控制台操作因电脑控制工具无法可靠识别浏览器当前网址而停止，本轮没有执行服务器更新，不能把下述新增能力记为线上已生效。

- 电脑连接在有效轮询或有效回执后续期。30 秒未续期即清理连接、结束长轮询、释放排队请求；状态查询、错误请求及手机请求不替电脑续期。过期连接不能用旧代数复活。
- 请求正文上传期间若电脑断开、重新注册或服务关闭，上传结束后重新检查连接代数，避免旧请求进入新连接。同一设备、同一请求编号的在途重复请求返回 409；完整的重放与执行去重仍由电脑端原协议负责。
- 上位机建立连接后遇到网络错误，按 1、2、4 秒递增、最长 30 秒的间隔重试；服务重启或连接代数失效时重新注册本机网关，保持本机设备身份和配对。401/403 停止自动重试。主动关闭连接会取消重试等待，不会在后台重新开启。
- 恢复后只拉取新请求。已经拉取但结果不明的指令、回执不会自动重发，仍应查询来源回执确认结果。初次连接失败继续显示错误，不在用户未启用连接时自动连接。

新增 `GET /v1/hosts/<channelId>/status`，必须使用该电脑的 Bearer 密钥；手机访问口令不能查询。返回服务发布标识、电脑是否在线、排队和已投递请求数量、长轮询状态及剩余连接有效时间；不返回密钥、配对信息、会话正文、密文或其他电脑的状态。读取此接口不会续期。

在项目目录运行以下命令可检查 HTTPS、鉴权和电脑状态；加 `--require-online` 后，电脑离线也会返回非零退出码。旧版服务器尚无状态接口，检查会明确显示状态不可用。

```powershell
node scripts/check-relay.mjs <本机私有服务器JSON路径>
```
